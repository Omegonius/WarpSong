A mod for https://www.owlbear.rodeo. It allows you to add music via YouTube links, which can be heard by both DMs and players, play multiple music streams simultaneously and control the volume of each track.

Мод для https://www.owlbear.rodeo. Дозволяє додавати музику через посилання на Ютуб яку буде чути як DM так і гравці, вмикати декілька стрімів музики одночасно, контролювати гучність кожного окремо.

Add it via the Owlbear mod manager: select ‘Add custom extension’ (the plus sign in the top right-hand corner), then paste this link into the window: https://warpsong.netlify.app/manifest.json

Додавати через мод менеджер owlbear, "add custom extension" (плюсик зправа зверху), у вікно вставити це посилання: https://warpsong.netlify.app/manifest.json
